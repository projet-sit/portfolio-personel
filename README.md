# Portfolio Ulrich IDOHOU

Portfolio one-page construit avec React, Tailwind CSS, Vite et Node.js.

## Lancer le projet en développement

```bash
npm install
npm run dev
```

## Générer et servir la version production

```bash
npm run build
npm start
```

Le serveur Node sert le portfolio sur `http://127.0.0.1:8085`.

## Modifier les informations

Les informations personnelles, compétences et projets sont dans `src/App.jsx`.
